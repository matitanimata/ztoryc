Ztoryc ships with whisper.cpp and a Whisper speech-recognition model, and uses
whisper.cpp through command line commands.
Ztoryc does not directly use whisper.cpp libraries or code.

whisper.cpp is used to obtain WORD TIMINGS for lip sync. The words themselves
come from the storyboard dialogue, not from the recognizer.

whisper.cpp source code can be found at:
https://github.com/ggml-org/whisper.cpp

The bundled model file (ggml-base-q5_1.bin) is a quantized GGML conversion of
OpenAI's Whisper "base" model, obtained from:
https://huggingface.co/ggerganov/whisper.cpp
